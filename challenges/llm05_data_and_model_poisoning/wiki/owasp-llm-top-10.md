# OWASP Top 10 for LLM Applications (2026)

The security team's summary of the 2026 list, used by the AI assistant.

1. LLM01 Prompt Injection: crafted input changes the model's behaviour, directly or through content it reads.
2. LLM02 Sensitive Information Disclosure: the application reveals data it shouldn't, including through RAG.
3. LLM03 Excessive Agency: the model gets more functions, permissions or autonomy than it needs.
4. LLM04 Supply Chain: models, packages or templates from untrusted or tampered sources.
5. LLM05 Data and Model Poisoning: training, fine-tuning or knowledge-base data is manipulated.
6. LLM06 Unbounded Consumption: requests run up uncontrolled cost or resource use.
7. LLM07 Misinformation: confident but wrong output that people or systems act on.
8. LLM08 Hidden Context Exposure: system prompts, tool schemas or hidden rules leak.
9. LLM09 Vector and Embedding Weaknesses: retrieval and vector stores are manipulated or leak across users.
10. LLM10 Improper Output Handling: model output is passed to other systems without validation.

The number one risk in 2026 is LLM01 Prompt Injection.
